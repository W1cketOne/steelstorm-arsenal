# Steelstorm Arsenal

A skill-based combat mod for **Minecraft Java 1.21.1** on **NeoForge 21.1.252**.

- **8 weapon types** in 6 tiers. Each tier of each weapon has its own 3D model and colours, and every weapon has its own swing animations. Netherite, Stormsteel and legendary weapons also get 3 abilities and an ultimate.
- **8 legendary weapons**, each with its own passive and ultimate.
- **Stamina** that dodge rolls, parries and heavy attacks all draw on.
- **Smithing**: runes, whetstones and Stormsteel armour.
- **Animations:** per-weapon swings, ability poses and a somersault dodge roll, seen in first and third person.
- **Combat feel:** glowing swing trails, every third combo hit is an overhead finisher, a zoom punch on hits, damage numbers that pop off enemies (gold for crits, blue for abilities), glowing cracks and debris under heavy slams, and boss title cards.
- **First person:** your arm grips the weapon; press **H** to inspect it, and heavy weapons rest on your shoulder when you stand still.
- **Glowing weapons light up the dark** (Stormsteel, netherite, diamond and legendary).
- **Movement animations:** players lean into sprints, stretch on jumps and squash on landing. With a weapon you carry it trailing (or across your chest for two-handers) while running and raise it mid-jump; in first person the weapon sways with your stride, lifts on jumps and dips when you land.
- **Big glowing effects:** shockwave halos, pillars of light, orbiting orbs, magic circles and sparkles.
- **Interactive blocks** and **6 bosses**, two of them fully custom animated models with their own lairs.
- **3D Stormsteel armour** with pauldrons, a crested helm and plating.
- **Eleven kinds of structures to explore**, an Explorer's Compass to find them, and a starter outpost next to your spawn.

All textures, models, particles and sounds are original. They are generated by the scripts in `tools/`.

The original design brief is in [PROMPT.md](PROMPT.md).

## 1. Play it (just the .jar)

1. Install **NeoForge 21.1.252** for Minecraft 1.21.1:
   - Download the installer from <https://neoforged.net/>, run it, and choose **Install client**.
   - The installer needs Java. If double-clicking does nothing, install Java 21 first (see section 2) and try again.
2. Start the NeoForge profile once:
   - Open the Minecraft Launcher and pick the **NeoForge 1.21.1** profile.
   - Press **Play** once so it creates its folders, then close the game.
3. Put `steelstorm-1.0.0.jar` into your **mods** folder:
   - **Windows:** press `Win + R`, type `%appdata%\.minecraft\mods`, and press Enter.
   - **Mac:** in Finder press `Cmd + Shift + G` and go to `~/Library/Application Support/minecraft/mods`.
   - If there is no `mods` folder, create one with exactly that name.
4. Start the NeoForge profile again and **create a new world**.

> Structures only appear in parts of the world you haven't explored yet, and the Warrior's Outpost is only built when a world is created. **Use a new world** to see everything.

**Multiplayer:** put the same jar in the server's `mods` folder (a NeoForge 21.1.252 server) and in every player's `mods` folder.

## 2. Run it from the source code

### Install Java 21

**Windows**
1. Go to <https://adoptium.net/temurin/releases/?version=21> and choose **Windows / x64 / JDK / .msi**. Run the installer.
2. On the "Custom Setup" page, turn on **Set JAVA_HOME variable**: click it and choose "Will be installed on local hard drive".
3. Open a **new** Command Prompt and type `java -version`. It should say `21`.

**Mac**
1. Go to <https://adoptium.net/temurin/releases/?version=21>, pick **macOS** and the **.pkg** download, and run it.
   - Choose **aarch64** if you have Apple Silicon (M1/M2/M3/M4).
   - Choose **x64** if you have an Intel Mac.
2. Open **Terminal** and type `java -version`. It should say `21`.

### Start the game with the mod

1. Download this repository: on GitHub, use **Code > Download ZIP** and unzip it, or use `git clone`.
2. Open a terminal **inside the project folder**:
   - **Windows:** Command Prompt, then `cd` into the folder.
   - **Mac:** Terminal, then `cd` into the folder.
3. Start Minecraft with the mod loaded:
   - **Windows:** `gradlew runClient`
   - **Mac:** `./gradlew runClient`. If it says "permission denied", run `chmod +x gradlew` first.

The first run downloads Minecraft and NeoForge, which takes a few minutes. To start a dedicated server instead, use `gradlew runServer`.

## 3. Build the .jar

- **Windows:** `gradlew build`
- **Mac:** `./gradlew build`

The jar is written to **`build/libs/steelstorm-1.0.0.jar`**.

**For developers:**
- If you change recipes, models, tags, translations or loot tables in the `datagen` package, run `gradlew runData` first. It rewrites `src/generated/resources`.
- The art and audio come from the Python scripts in `tools/`, for example `python3 tools/gen_textures.py`:
  - Textures: `gen_textures.py`, `gen_icons.py`, `gen_fx.py`, `gen_blocks3.py`, `gen_skins.py`
  - 3D models: `gen_models.py`
  - Sounds: `gen_sounds.py`
- They need `pip install pillow numpy scipy soundfile`.

## 4. Controls

| Action | Default key | Notes |
| --- | --- | --- |
| Ability 1 / 2 / 3 | **R** / **G** / **V** | Each weapon type has its own three. Each has a cooldown and costs stamina. |
| Ultimate | **Z** | Charges from dealing and taking damage. The icon glows when it's ready. |
| Dodge roll | **Left Alt** | Rolls about 3 blocks the way you're moving. You can't be hurt for a moment. Costs 20 stamina. |
| Guard / parry | **Hold right-click** with a melee weapon | Get hit just as you raise your guard for a **perfect parry**: no damage, and the attacker is staggered. After that, guarding blocks half the damage and costs stamina. |
| Heavy attack | **Sneak + attack** | 1.5x damage and extra knockback. Costs 15 stamina. Needs a fully charged swing. |
| Throw spear | **Sneak + hold right-click**, then release | Pick the spear up again afterwards. |
| Throw chakram or knife | **Right-click** | The chakram bounces between enemies and comes back. |

- The **ability bar** sits to the right of the hotbar. It shows each ability's icon, its key, its cooldown, and the ultimate meter. Your **stamina bar** sits above the hunger bar.
- Hold **Shift** while hovering over a weapon to read what its abilities do.
- To change keys: **Options > Controls > Key Binds > Steelstorm Arsenal**.
- To change settings: **Mods > Steelstorm Arsenal > Config**.

## 5. Weapons and abilities

There are six tiers: Stone, Iron, Gold, Diamond, Netherite and Stormsteel. Netherite weapons are made at a smithing table from diamond ones. Every weapon has a **passive** that is always on. **Abilities and the ultimate unlock only on Netherite, Stormsteel and legendary (purple-named) weapons**; lower tiers keep the passive and the swing animations.

**Charges:** abilities marked *(N charges)* can be used N times in a row. Pips above the icon show the charges left, and they refill one at a time.

**Sounds:** every ability has a signature sound on top of its own effects. Slams get an earth-shattering boom, thrown blades sing, scythe powers growl, dashes rush like wind, and war cries roar like fire. Ultimates release with a trailer-style hit, and Stormsteel ultimates add a thunderclap. Holding Z plays a rising charge sound.

**Charged ultimates:** tap **Z** to fire your ultimate, or **hold Z** to charge it. A gold bar fills above the icon and the damage grows up to **x1.75** after 2 seconds; release to unleash it. A full charge adds an extra blast of light.

| --- | --- | --- | --- | --- | --- |
| **Longsword** | Every 3rd hit in a row deals +30% | Sword Toss (3 charges): hurl glowing copies of your sword | Riposte: a parry stance that answers the next blow | Blade Dash (2 charges): dash 6 blocks, cutting through enemies | **Judgment of Steel**: seven giant spectral swords rain down |
| **Greatsword** | Wide sweeping strikes | Titan's Guard: soak up 75% of every blow for 3 s, then blast it all back | Crescent Wave (3 charges): a flying wave of force | Sword Sanctum: plant a giant spectral sword that pulls in, burns, then explodes | **Colossus Strike**: a 16-block fissure tears open |
| **Katana** | Critical hits cause Bleed | Flash Step (3 charges): vanish 7 blocks ahead, cutting everything you pass | Iaido: one lightning-fast draw cut | Wind Scar: three crossing blades of wind that bleed | **Thousand Cuts**: blink between up to eight enemies |
| **Dual Daggers** | Double damage from behind | Flurry: five quick stabs | Shadowstep: appear behind your target | Fan of Knives (3 charges): twelve spectral knives in a ring | **Death Blossom**: become invisible and deadly for 5 s |
| **Spear** | Can be thrown | Impale: pierce and pin a 7-block line | Vault Leap: pole-vault forward | Sweeping Arc: a huge sweep that throws enemies back | **Dragon Dive**: leap high and dive onto a spot up to 20 blocks away |
| **Warhammer** | Hits cause Armor Break | Earthquake: a 7-block shockwave that ripples through the ground | Hammer Throw: hurl the hammer; it comes back | Stone Prison: seal an enemy in rock, then shatter it | **Cataclysm**: leap and crash down like a meteor |
| **Scythe** | Heals you for 10% of damage dealt | Reap: a full-circle life-draining sweep | Soul Harvest: drag and Mark everything within 9 blocks | Death's Crescent (2 charges): a returning crescent of death | **Death Mark**: doom everything near; 3 s later it takes heavy damage plus half of what it took meanwhile |

**Thrown weapons** (the chakram and throwing knives) have no abilities; they are thrown with right click.

## 6. Smithing and upgrades

### Whetstone

- **Recipe:** flint on top, a grindstone in the middle, planks around it.
- **Use it:** right-click it with a weapon. The weapon gets **+2 damage for its next 20 hits**.

### Runes and the Rune Forge

There are six runes:

| Rune | Effect on hit | Crafting ingredient |
| --- | --- | --- |
| Ember | Sets enemies on fire | blaze powder |
| Frost | Slows enemies | packed ice |
| Storm | 30% chance to arc lightning to another enemy | Stormsteel ingot |
| Venom | Poisons | fermented spider eye |
| Vampiric | Heals you for 8% of the damage you deal | ghast tear |
| Gale | Blasts enemies back | feather |

- **Crafting a rune:** 2 amethyst shards + lapis lazuli + the ingredient from the table. Runes are also found in loot and sold by weaponsmiths.
- **Rune Forge recipe:** amethyst shards on top, iron + smithing table + iron in the middle, polished blackstone on the bottom.
- **Applying a rune:** place it on a Rune Forge, then use your weapon on the forge. The rune is burned into the weapon, replacing any old one.

### Stormsteel

- **Finding it:** Stormsteel ore generates in mountain and windswept biomes, from deep underground up to the peaks. Smelt raw Stormsteel into ingots.
- **Weapons:** the tier between diamond and netherite. Stormsteel weapons sometimes zap a second nearby enemy.
- **Armour:** crafted like iron armour. Every piece has its own power:
  - **Helmet, Storm Sight:** hostile mobs within 24 blocks glow through walls (only you see the outline).
  - **Chestplate, Static Barrier:** every 20 seconds the next hit is fully absorbed and nearby attackers are zapped and blasted away.
  - **Leggings, Lightning Sprint:** sprint for 1.5 seconds to surge to Speed II, leaving a spark trail.
  - **Boots, Thunder Step:** press jump in mid-air to **double jump**. Landing from 4+ blocks sends out a damaging shockwave instead of hurting you.

  The full set also gives the **Stormcaller** bonus:
  - 10% faster movement
  - immunity to lightning
  - enemies that hit you in melee may get zapped

### Ember Warlord armour

A second 3D armour set: blackened, horned plate with molten seams. Craft each piece from the matching **Stormsteel piece** in the centre, with **2 netherite ingots** at its sides, **4 blaze rods** in the corners and **2 magma cream** above and below.

- **Helm, Infernal Eyes:** night vision; blindness and darkness can't touch you.
- **Cuirass, Magma Heart:** melee attackers are scorched and set ablaze.
- **Greaves, Scorched Path:** sprint into enemies to bowl them aside in flames.
- **Sabatons, Meteor Fall:** sneak in mid-air to slam down, sending out a fiery shockwave that cracks the ground.
- **Full set, Warlord's Wrath:** immune to fire and lava, and your strikes set enemies ablaze.

### Weaponsmiths

Villager weaponsmiths sell the following, depending on their level:
- iron longswords, throwing knives and random iron weapons
- chakrams, whetstones and runes
- diamond weapons
- Stormsteel ingots and the Rune Forge

## 7. Enemies and bosses

| Enemy | Where | Notes |
| --- | --- | --- |
| Bandit Duelist | Bandit camps, watchtowers, arena waves | Parries and lunges. |
| Bandit Archer | Bandit camps, watchtowers | Keeps its distance. |
| Iron Revenant | Night-time overworld, mines, armories | A slow armoured knight with a ground slam. |
| **Bandit Captain** (80 HP, boss bar) | Bandit camps, final arena wave | War cry, leap, whirlwind. Drops the **Vault Key**. |
| **Crypt Knight** (120 HP, boss bar) | Knight's Crypt sarcophagi | Ground cleave and soul dash. Calls a soul shield and skeletons at half health. |
| **The Storm Herald** (260 HP, boss bar) | Summoned at a Storm Altar | Flies and calls lightning on marked spots. Throws storm crescents. In phase 2 it dive-bombs and is stunned after each dive, which is your chance. Drops a legendary. |
| **The Fallen Warlord** (300 HP, boss bar) | Ruined Colosseums | Three phases: greatsword attacks, then summoned Revenants, then an enraged leap. Drops a legendary. |
| **The Forge Colossus** (420 HP, boss bar) | Colossus Forge lairs | A 3-block-tall war machine. Ground Pound, Hammer Sweep, Charge and Molten Barrage, with marked landing spots. At half health it Overheats: summons Revenants, then erupts geysers. Drops a legendary and lots of Stormsteel. |
| **The Moonblade Revenant** (320 HP, boss bar) | Moonlit Sanctum lairs | A floating four-armed swordswoman. Crescent Volley, Blink Strike behind you, Blade Dance. At half health she Eclipses: darkness, faster attacks, Moonfall sword rain. Often drops Moonveil. |

**Reading big attacks:**
- **The warning:** the enemy stops, raises its weapon, glows and plays a sound. That's your cue to dodge or parry.
- **Your opening:** after a big attack it pauses briefly.

Boss bars appear when you get within about 40 blocks.

## 8. Structures

**Finding them:**
- All eleven kinds are spread across the overworld, about one every 160 blocks.
- They are never built on top of each other or inside villages.
- Each one clears its own glade.
- To find the nearest one, use `/locate structure steelstorm:<name>` with one of the names in brackets below.

### Explorer's Compass
- **Crafting:** a compass, three gold ingots and an amethyst shard. There's also one in the starter chest.
- **Using it:** right-click to find the nearest structure of the chosen kind (distance, direction and coordinates). Sneak + right-click to choose which kind.

### Colossus Forge (`colossus_forge`, boss lair)
- A ring of basalt walls with lava channels around a great anvil.
- The Forge Colossus stands guard. Defeat it and the Champion's Coffer behind the forge unlocks.

### Moonlit Sanctum (`moonlit_sanctum`, boss lair)
- A pale quartz circle ringed by crystal-crowned pillars.
- The Moonblade Revenant dances at its heart. Defeat her to unlock the coffer.

### Warrior's Outpost
Built once, next to spawn, when a world is created. Inside are:
- weapon racks and target dummies
- a whetstone and a Signal Brazier
- a starter chest with the **Warrior's Handbook**, which explains everything in-game

### Abandoned Armory (`abandoned_armory`)
- A crumbling stone armory.
- Has loot chests, a weapon rack, a whetstone and an old suit of chainmail.
- Sometimes an Iron Revenant still guards it.

### Watchtower (`watchtower`)
- A three-storey bandit tower.
- Climb the ladder past loot on each floor to the lookout, where archers wait.
- A Signal Brazier is on top.

### Bandit Camp (`bandit_camp`)
- A ring of stakes around tents, a campfire, a lookout post and a caged prisoner you can free.
- **The vault:** the captain's tent holds a locked **Bandit Vault**. Defeat the **Bandit Captain** for the **Vault Key**.

### Blacksmith's Forge (`blacksmith`)
- A working smithy with an anvil, furnaces, a lava crucible and a whetstone. Some have a **Rune Forge**.
- Weapons hang on the porch racks.
- A **weaponsmith** sells Steelstorm gear.

### Proving Grounds (`proving_grounds`)
- A training arena behind a palisade, with dummies, racks and champion statues.
- **The challenge:**
  1. Strike the **Arena Gong** to fight three waves of challengers. The last wave brings a Bandit Captain.
  2. Win, and the **Champion's Coffer** unlocks.

### Stormsteel Mine (`stormsteel_mine`)
- **On the surface:** a headframe over the shaft, the miners' shed and an ore heap.
- **Below:** climb down the ladder to a chamber glittering with Stormsteel ore. Two timbered tunnels run off it.
  - One tunnel has caved in.
  - The other ends in a rich vein.
- The dead miners still walk as Iron Revenants.

### Knight's Crypt (`knights_crypt`)
- A walled graveyard with a mausoleum. Stairs inside lead down to a buried hall of four **sarcophagi**.
- **Opening a sarcophagus:**
  - It spills grave goods.
  - It wakes a **Crypt Knight**, or skeletons if a knight is already up.
- **The pedestal:** a **Legendary Pedestal** on the dais holds a legendary or a top-tier weapon.
  - It stays sealed until every sarcophagus is open and its knights are dead.

### Storm Shrine (`storm_shrine`)
- A raised circle of storm-blackened stone, ringed by lightning-rod pillars.
- **Summoning the Storm Herald:** offer **four Stormsteel ingots** at the **Storm Altar** and the Herald comes down in a lightning storm.

### Ruined Colosseum (`ruined_colosseum`, rare)
- The Fallen Warlord's arena.
- It also has an Arena Gong and a Champion's Coffer.

### Interactive blocks
You can also craft most of these yourself:

| Block | What it does |
| --- | --- |
| Weapon Rack | Displays up to 3 weapons. |
| Target Dummy | Shows the damage of every hit and your DPS. Sneak-punch it with an empty hand to pick it up. |
| Whetstone | Sharpens a weapon (see section 6). |
| Rune Forge | Burns a rune into a weapon (see section 6). |
| Signal Brazier | Light it with flint and steel: nearby monsters glow through walls and you get night vision while it burns. |
| Arena Gong | Starts a 3-wave arena challenge. It rests 5 minutes between challenges. |
| Champion's Coffer / Bandit Vault | Locked loot chests, opened by an arena victory or a Vault Key. |
| Sarcophagus | Opening it wakes the dead. Placed by players, it starts empty. |
| Legendary Pedestal | Holds a weapon. Guardians or closed tombs nearby seal it. |
| Storm Altar | Summons the Storm Herald. |

## 9. Config

Settings live in `config/steelstorm-common.toml`:
- stamina: maximum, regeneration and costs
- damage multipliers, and the cooldown and ultimate-charge multipliers
- parry and dodge timings
- how often each structure appears (0 turns that structure off)
- whether to build the starter outpost

Settings in `steelstorm-client.toml`:
- screen shake strength
- the combo counter

## 11. Things that were simplified

- **Chakram and Throwing Knives** are single items, not one per tier.
- **Enemy models:**
  - The Forge Colossus and the Moonblade Revenant have fully custom keyframe-animated models.
  - The other enemies use the player-shaped model with their own skins, plus swing and slam animations.
- **Structures are built in code** rather than from hand-made `.nbt` files.
  - Their layouts are fixed, and only the loot, ruins and details vary.
  - How often they appear is set in the structure set JSON plus the config chances.
- **Spear throwing** uses sneak + hold right-click, because plain right-click is the guard/parry for every melee weapon.
- **Stagger** stops melee hits, but a staggered archer can still shoot.
- **Sounds** are synthesized by a script (`tools/gen_sounds.py`), not recorded.
- **Spawn point:** when the outpost is built, the `spawnRadius` game rule is set to 0, so everyone spawns exactly at its door.
- **Mod compatibility:** only tested on its own with NeoForge 21.1.252.
