# Steelstorm Arsenal

This repo is a Minecraft Java 1.21.1 NeoForge mod. The full build brief is in PROMPT.md: read it first and follow it.

- Start from the official NeoForge MDK: https://github.com/NeoForgeMDKs/MDK-1.21.1-ModDevGradle
- Run `./gradlew build` and fix every error before finishing a phase.
- Commit and push after each phase.
