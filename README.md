# Steelstorm Arsenal

A skill-based combat mod for Minecraft Java 1.21.1 (NeoForge): 10 weapon types, stamina, dodging, parrying, special moves, new enemies, a boss, and structures, including a starter outpost next to your spawn.

The full design brief is in [PROMPT.md](PROMPT.md). Build instructions will be added here once the mod is built.
